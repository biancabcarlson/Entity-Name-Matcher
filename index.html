Entity Name Matcher

Check whether two names — people or organizations — plausibly refer to the same entity, accounting for nicknames, initials, reordered or dropped tokens, transliteration drift, and legal-suffix noise. Same scoring logic as the entity_name_matcher.py CLI in this repo.

No data is sent anywhere — matching runs entirely in your browser. Part of the investigator tool series alongside Case Calculator, Case Timeline Builder, OSINT Query Fanout, Case Doc Tracker, and Report Template Filler.
